First released on 05/25/2026. 

This repository contains simulation data and plotting scripts for W. Ying and A. Nitzan, "Excitation density controlled regimes of collective light-matter dynamics," arXiv:2605.24227.

Updated on 07/05/2026: Fig. 3, Fig. S1, and Fig. S2 scripts were revised in response to reviewer comments. 

Folders:

- `Fig1`: schematic and table-of-contents assets.
- `Fig2`: MF convergence data and plotting script.
- `Fig3 and S1`: revised Fig. 3 and Fig. S1 workflows. Run the single-emitter CE2/CE3 scripts, the fourth-order diagnostic/projected-algebra scripts, and the many-N CE2 scan before `plotting_fig3.py` and `plotting_figS1.py`.
- `FigS2`: detuning-robustness workflow for the MF-SE bright-vibrational-mode comparison.
- `Fig4`: SE/MF bright-vibrational-mode convergence workflow.

Generated manuscript figures are written to `Figures/`.

Updated on 07/19/2026: glad to announce that the paper has been published on J. Phys. Chem. Lett., see https://pubs.acs.org/doi/full/10.1021/acs.jpclett.6c01689
